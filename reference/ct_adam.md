# ADaM Controlled Terminology

Versioned CDISC ADaM Controlled Terminology from the NCI EVS FTP site.
Same validity-date design as
[`ct_sdtm`](https://humanpred.github.io/cdiscdata/reference/ct_sdtm.md).

## Usage

``` r
ct_adam
```

## Format

A data frame with the same columns as
[`ct_sdtm`](https://humanpred.github.io/cdiscdata/reference/ct_sdtm.md).

## Source

<https://evs.nci.nih.gov/ftp1/CDISC/ADaM/>
