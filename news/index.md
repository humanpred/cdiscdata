# Changelog

## cdiscdata 0.1.0

- First release of `cdiscdata`.
- Bundles versioned CDISC SDTM and ADaM Controlled Terminology from the
  NCI EVS FTP site using a compact validity-date design.
- Includes Define-XML XSD schemas (2.0, 2.1) and XSLT stylesheets.
- Key functions:
  [`get_ct()`](https://humanpred.github.io/cdiscdata/reference/get_ct.md),
  [`get_dataset()`](https://humanpred.github.io/cdiscdata/reference/get_dataset.md),
  [`available_ct_versions()`](https://humanpred.github.io/cdiscdata/reference/available_ct_versions.md),
  [`schema_path()`](https://humanpred.github.io/cdiscdata/reference/schema_path.md),
  [`stylesheet_path()`](https://humanpred.github.io/cdiscdata/reference/stylesheet_path.md),
  [`list_datasets()`](https://humanpred.github.io/cdiscdata/reference/list_datasets.md),
  [`cdiscdata_versions()`](https://humanpred.github.io/cdiscdata/reference/cdiscdata_versions.md).
